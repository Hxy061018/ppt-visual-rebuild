# PPT Visual Rebuild · 精致 PPT 制作

**一个用于制作精致、美观、可编辑 PPT 的 Codex Skill。**

[English](README.md) · [简体中文](README.zh-CN.md)

第一步直接做出完整可编辑稿，再逐页检查，通过生图重构风格与版式，最后高比例复刻为可编辑页面。

```text
可编辑初稿 → GPT视觉检查 → 生图重构风格与版式 → 可编辑复刻 → 渲染验收
```

## 核心能力

- 先做出第一版，不停在规划文档。
- 检查范围内每一页，需要时可以重做大部分甚至全部页面。
- 为问题页生成设计参考，不只是加几个装饰图标。
- 标题、正文、表格、数字、关键图示和连线用可编辑对象复刻。
- 按要求保留页眉、页脚、校徽、母版等固定结构，重点升级主体。
- 成稿同时对照原始内容、生图参考和受保护区域验收。

插画与照片可保留为图片；不会将整页图片冒充可编辑稿。真实截图、评论和数据始终以原始材料为准。

## 使用方式

从 [Releases](https://github.com/Hxy061018/ppt-visual-rebuild/releases) 下载中文或英文 ZIP。每个压缩包包含 `ppt-visual-rebuild/` 文件夹，内有 `SKILL.md`、`agents/` 和 `references/`。

如需安装，将**其中一个版本**的 `ppt-visual-rebuild` 文件夹复制到 Codex 技能目录，通常为 `~/.codex/skills/`。两版标识相同，不要按同一标识同时安装两版。下载或克隆仓库不会自动安装。

调用示例：

```text
使用 $ppt-visual-rebuild，根据这些材料制作精致美观的PPT。
先直接做出完整可编辑初稿，再逐页检查、生图重构风格与版式，
最后高比例复刻成可编辑页面。保留现有页眉页脚，总页数不超过20页。
```

修改现有稿：

```text
使用 $ppt-visual-rebuild 升级这份PPT的第8–16页。
保留已确认内容、页眉、页脚和校徽，为需要改进的页生成主体设计参考，
然后用可编辑文字和结构高比例复刻。
```

## 环境与适用范围

本仓库提供工作流指令和可复用提示词，不自带 PPT 渲染引擎或生图接口。运行环境需具备可编辑演示稿创作、渲染、看图和生图能力。Skill 会配合当前可用的演示稿、生图技能，也可调用其他适用技能辅助初稿和素材。

不内置密钥、固定模型或本机路径；能力缺失时要求准确说明。视觉检查可由当前多模态助手执行，不会自动调用另一个 GPT 服务。

不固定套用某种配色或插画风格，不擅自加页、不编造证据、不修改保护区域。高比例还原是设计目标，必须通过渲染检查，不保证像素级一致。
