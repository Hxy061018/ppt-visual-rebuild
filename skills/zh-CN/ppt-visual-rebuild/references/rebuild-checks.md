# 复刻施工与质量检查

## 坐标与保护区

记下画布宽高及主体边界。主体为 `(x0,y0,w,h)`，参考图相对主体的位置为 `(u,v)`，则目标为 `(x0+u*w,y0+v*h)`。统一单位转换，避免逐项目测造成比例漂移。

保护区随页面而异，章节、正文和结束页不必同一外壳；记录允许改变的例外。“保留页眉页脚”既不妨碍调整正文，也不等于只保留文字却随意移动标识。

## 分层施工

1. 原生外壳、背景及母版关系。
2. 主体轮廓：栏、卡片、环、表格、流程及图片占位。
3. 源内容与真实证据，检查阅读顺序。
4. 插画、图标、图片裁切、阴影及装饰。
5. 基线、内边距、字级、连接点及层级。

环形关系、箭头卡片、时间线优先原生组合，不因复杂直接栅格化。纹理或复杂轮廓可作底图，上层文字与关键结构仍可编辑。

## 常见失败

| 失败 | 处理 |
| --- | --- |
| 参考美观但内容放不下 | 保留事实并重组区块，必要时重新生图，不强行缩字 |
| 生成文字或数字错误 | 用源内容原生替换，生成图不作事实来源 |
| 截图指标太小 | 保留截图，真实局部裁切放大并原生标注，不AI重画 |
| 图标杂乱 | 统一图标家族、线宽、填充、底圈和尺寸 |
| 纯色在播放器出现渐变或立体效果 | 检查继承的主题效果及样式引用，显式设定填充和效果后渲染 |
| 标识变形 | 保持比例并检查裁切，不拉伸 |
| 校验器报告原稿已有问题 | 对基线区分新增问题，不为消除旧警告擅改保护页 |
| 内部文件编号和页序不同 | 读取演示文稿实际页面关系及逻辑顺序 |
| 评论截图重复 | 核查重复材料，不当作独立证据，按展示价值去重 |

## 验收证据

- 初稿渲染、逐页台账、实际生成参考及最终渲染齐备。
- 所有范围内页面已审阅，重做页已对照选定参考逐页检查。
- 标题、结论、数字、图表和真实证据已对源核验。
- 保护区与基线一致；页数、顺序、画幅符合最新要求。
- 无意外溢出、裁切、遮挡、图片失真或不可读细字。
- 文字及关键结构能编辑，图片承担合适素材任务。
- 条件允许时查看PowerPoint实际渲染；使用其他渲染器关注字体及效果差异。
- 保留用户现有应用，不为渲染随意关闭窗口或退出应用。
