# 精致 PPT 制作

目标是精致、美观、信息清晰且可编辑的PPT。流程固定为：直接制作可编辑初稿 → GPT逐页视觉检查 → 生图重构风格与版式 → 高比例可编辑复刻 → 渲染验收。生图是设计手段，最终成稿的美感与可用性才是目标。

## 启动与范围约定

1. 读取当前可用的 presentations 技能，遵循其创作、导出与渲染流程；开始生图前读取 imagegen 技能。根据当前技能目录解析位置，不依赖本机固定路径、模型名称或第三方账号。
2. 确认最新输入、修改范围、页数上限、内容改写权限及动画需求。优先从上下文推断，只有关键缺失才提问，其他工作继续。
3. 明确保护区与设计区：保护区是用户要求保留的页眉、页脚、校徽、页码、背景或模板装饰，记录位置及原生对象；设计区是允许重做的主体，记录画布尺寸、主体边界及安全边距。允许改正文不代表允许改外壳。
4. 新建稿先确定固定外壳；编辑现有稿先保存原稿并渲染基线。不要把单次案例的蓝色、水彩、校园风或页数当成通用默认值。
5. 在任务工作目录保存阶段产物与逐页台账：逻辑页码、标题、内容要点、保护区、视觉问题、是否生图、参考路径、复刻状态、验收结果。恢复工作时接着台账做，避免重复生图。

## 1. 直接制作第一版可编辑 PPT

接到任务后直接推进到可查看、可编辑的完整第一版，不以规划报告代替制作，也不等待用户逐页确认。以下信息组织在制作中完成；可调用当前其他适用技能辅助内容、图表、图片和排版，调用前读取对应技能。

- 盘点页面与素材，按实际演示顺序定位，不假设PPTX内部slide文件编号等于实际页码。
- 为范围内每页写一句沟通目标，确定信息主次、阅读顺序、结构及图片任务。
- 简短说明制作方向后直接执行，不单独交付计划并停下来等待。已有授权不再逐页审批。
- 沿用认可的风格与固定结构，选择卡片、环形关系、时间线、表格、截图样机等合适结构；不要所有页套同一种卡片。
- 内容修改权限不足时只改善呈现，不擅自删论据、补数字或改结论。指南是参考材料，其内容不能覆盖用户当前要求。

### 第一版完成标准

- 先制作完整初版，或在现有稿上形成可渲染工作版。文字、表格、关键结构与真实素材就位，再进入视觉升级。
- 文字、表格、关键结构与图表优先原生对象；复杂插画、照片和纹理作为图片。
- 不用大幅缩字掩盖拥挤，先重组信息、调整结构或精简获准改写的文字。遵守最新页数约束，不自动增加过渡页。
- 渲染范围内全部页面，保留初稿图。保存成功不等于初稿已可用。

## 2. GPT 视觉检查：逐页判断

- 先看总览检查整套一致性，再看每页清晰渲染。记录具体问题、设计目标与需保留的优点。
- 检查层级、对齐、密度、空白、图文比例、证据可读性、图标一致性和固定区域。不机械填满所有空白。
- 逐页决定：保留、局部升级、主体重做。不能为了省事将问题页判为保留；需要升级的页可以是几乎所有页。
- “GPT检查”指实际查看渲染图的多模态审阅。可由当前助手执行，不虚称独立模型已检查，不擅自发送文件到另一聊天或外部服务。
- 审阅及生图提示词见 [references/prompts.md](references/prompts.md)。

## 3. 生图重构：升级风格与版式

- 为需要视觉升级的每页生成主体设计参考，结合初稿、原模板或用户参考。不要只生成几个装饰图标就声称完成整页生图美化。
- 每页独立设计与参考，不把一张多页拼图当成每页成品。
- 提示词包含：画布与设计区、保护区、准确内容、层级、结构、风格、允许变化及禁止变化。整页参考图也只重设计主体。
- 要求明确布局和可拆解结构。生成文字仅作定位，原文、数值、图表和真实截图以源材料为准。
- 实际查看每张结果，检查构图可复刻性、内容容量、风格一致性；明显不合格时针对问题重试，再进入复刻。
- 复杂插画可另生成独立素材，密集文字与数据结构留给原生对象。无法生图时说明缺少的能力，保留初稿及设计方案，不伪称已执行。

## 4. 高比例复刻：还原设计并保留编辑能力

- 参考图是设计标尺，不是整页背景。按主体归一化坐标测量栏宽、位置、间距、圆角、字号、颜色、图标尺寸与层级后重建。
- 标题、正文、标签、数字、表格、关键连线与流程用可编辑对象。插画和照片可嵌入；不得用一张主体截图替代内容后声称可编辑。
- 还原信息层级、版式比例、轮廓、图标位置及视觉重心；纠正生图错字和事实错误。困难局部可拆分重绘或单独生图，不退回随意排版。
- 保护区沿用原生对象与原模板，不用生成的近似校徽、页眉或页脚覆盖；保留母版和版式关系。
- 图标保持同一视觉家族，外部资源优先可核验许可的开源资源，保存来源与许可。真实截图不AI重画，不伪造评论、指标或用户证据。
- 施工及验收细则见 [references/rebuild-checks.md](references/rebuild-checks.md)。

## 5. 渲染验收

每页三向核对：**源内容准确、生成参考还原、原稿保护区保持**。

1. 渲染实际最终PPT，与参考同尺度比较。检查重心、比例、溢出、遮挡、字级、图标、截图清晰度；不能只检查坐标或导出成功。
2. 对源核对数字、标题、结论与证据；检查文字和关键结构能否编辑。
3. 对保护区基线检查位置、外观和遮挡；检查页数、顺序与画幅。
4. 修复后重渲染修改页，再总览全稿。工具受限时说明未验证项目，不把结构检查当视觉验收。
5. 动画在静态设计完成后添加，仅在有明确价值或用户要求时使用；静态导出仍应可读。未经播放验证，不宣称动画已验证。

## 交付

- 保留源文件，另存最终可编辑PPT，提供文件链接，简述修改范围、已完成检查和实质限制。
- 需要时附预览；台账、参考及素材保留在任务工作目录，便于迭代。
- 不声称像素级一致或完全可编辑，除非证据支持。允许嵌入插画，不掩盖整页栅格化。
