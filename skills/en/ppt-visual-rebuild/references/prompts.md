# Reusable prompts

Replace bracketed fields for each project. Generation input must be self-contained; do not expect the image tool to read files that were not supplied. Follow the current imagegen skill for passing reference images.

## A. Slide-by-slide visual review

Inspect the draft renders under these constraints: [scope], [fixed elements], [style], and [slide limit].

For each slide, identify its communication goal and reading order; concrete problems with locations and causes; content and strengths to retain; a keep/local-upgrade/body-redesign decision; and the target structure, image-to-text ratio, palette, icon tasks, and problems image generation should solve.

Inspect every slide in scope. Do not infer small-text accuracy from thumbnails. Exclude protected headers and footers from redesign. Replace vague requests for a more premium appearance with actionable design goals.

## B. Image-generated body redesign

Generate a polished visual redesign reference for one slide, suitable for close reconstruction using native objects.

- Canvas: [aspect ratio and dimensions]. Body design region: [coordinates or proportions].
- Fixed regions: [headers, footers, logos, and bounds]. Redesign only the body; retain fixed-region positions and appearance.
- Communication goal: [one sentence].
- Required text and facts: [exact wording, numbers, and labels by hierarchy].
- Real materials: [screenshots, charts, photos, and their roles]. Do not fabricate substitute evidence.
- Structure: [columns, circular relationships, timeline, etc.; proportions, reading order, and connector meaning].
- Visual language: [project palette, typography character, illustration and icon style].
- Reference elements to adopt: [specifics]. Prohibited changes: [actual user constraints].

Create a complete, coherent, readable body design with intentional whitespace, suitable for projection. Icons must carry clear meaning. Reserve space to rebuild tables, titles, and numbers as native objects. Do not bury essential content inside complex artwork. Output one slide, not a multi-slide collage.

## C. Reconstruction brief

Use the selected reference to rebuild the body as an editable PPT. First specify protected regions, body bounds, coordinates, column widths, row heights, type hierarchy, palette, image crops, and layers. Distinguish native structures from image assets.

Preserve original fixed regions. Rebuild titles, text, numbers, tables, nodes, and connectors natively. Correct errors against the source. Complex illustrations may remain images; do not flatten the slide. Match structure and proportions first, then typography, icons, shadows, and decoration. Split difficult areas into smaller tasks.

## D. Reconstruction acceptance

Inspect the source, selected reference, and final render side by side. Compare bodies at the same scale and check protected regions separately.

Check reading order, proportions, spacing, type hierarchy, colors, silhouettes, crops, icons, connectors, small text, facts, protected regions, and editability. List passed checks and concrete repairs. For each repair, identify the object, discrepancy, remedy, and priority. Fix overflow, wording, false evidence, and structural distortion first. Mark anything not actually inspected as unverified.
